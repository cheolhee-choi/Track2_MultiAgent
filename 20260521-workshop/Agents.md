# 에이전트 역할 정리

## 1. 기획 오케스트레이터
- 대시보드 전체 요구사항을 쪼개고 우선순위를 정한다.
- 작업 순서와 담당 범위를 정리한다.

## 2. UI/UX 디자이너
- 정보 구조, 레이아웃, 상태 표현을 설계한다.
- 자연스럽고 과하지 않은 화면 방향을 제안한다.

## 3. 데이터/상태 설계자
- 에이전트 상태, 큐, 로그, 이벤트, 결과물의 데이터 구조를 정의한다.
- 대시보드에서 읽을 수 있는 최소 데이터 모델을 만든다.

## 4. 구현 에이전트
- 실제 코드와 연결되는 UI 구조를 구현한다.
- 동작 가능한 초안을 우선 만든다.

## 5. 코드 리뷰어
- 구현물의 결함과 애매한 부분을 비판적으로 검토한다.
- 수정하지 않고 문제와 리스크를 정리한다.

## 6. TDD 에이전트
- 핵심 흐름을 검증하는 테스트 초안을 작성한다.
- 실패 케이스와 경계 조건을 함께 다룬다.

## 7. QA/검증 에이전트
- 실제 사용자 흐름 기준으로 결과를 점검한다.
- 로딩, 오류, 빈 상태를 확인한다.

## 공통 원칙
- 역할 외 작업은 하지 않는다.
- 모호한 요구는 추측하지 않고 표시한다.
- 대시보드 핵심은 상태 가시화와 흐름 추적이다.
